# Візуальний Інструмент Тестування Алгоритмів Кластеризації

> [!TIP]
> Команда для запуску: `python -m Algorithms` з директорії на рівень вище теки "Algorithms".

![image](https://github.com/user-attachments/assets/37c2bb5d-f729-452f-97be-68449a1d4435)

Перш ніж переходити до кластеризації, необхідно створити підходящій тестовий набір. У цьому нам допоможе інтерфейс генерації наборів.

![image](https://github.com/user-attachments/assets/ccbb7d49-5b72-4587-be26-69921039710e)

Точки концентрації - це точки, навколо яких буде утворено скупчення об'єктів під час генерації.
За відсутності точок концентрації, набір генерує поле точок за нормальним розподілом.
Згенерований набір грубо повторює форму, "намальовану" точками концентрації зі зміщенням генерації `scale` або `sigma`.

Точку концентрації можна додавати окремо, або образу згенерувати набір таких точок:
![image](https://github.com/user-attachments/assets/c8f703d2-fdcf-4a77-9bc2-099eafafbedb)
![image](https://github.com/user-attachments/assets/ddf7e193-119d-46b9-a6c8-55d17efbe999)

> [!NOTE]  
> Виділену в списку точку концентрації можна усунути натисканням відповідної кнопки.

Точки відобразяться на графіку.
![image](https://github.com/user-attachments/assets/35b8d117-b173-4d28-b5fb-72686ca320fa)

Згенерувати, безпосередньо, набір інформаційних об'єктів, можна натиснувши кнопку `Утворити Тестовий Набір`, після чого він з'явиться на графіку.
![image](https://github.com/user-attachments/assets/963fa418-5a32-4a66-87a8-8f1ea5658efa)

Після того, як Ви згенерували тестовий набір, можна переходити до кластеризації. У меню налаштувань з'явиться відповідний розділ:
![image](https://github.com/user-attachments/assets/5e5734fd-0a44-415d-8ac2-9532c7dd4c65)

Програма шукає усі метрики та алгоритми у теці "Algorithms", та представляє їх на вибір користувача.
Назва елементів у цих списках - це назва файлів коду (без розширення), де і виявлено безпосередню сигнатуру функції.

> [!WARNING]  
> Так, як пошук виконується за сигнатурою функції, важливо тримати лише один алгоритм чи метрику у відповідному файлі.

Нижче представляються усі додаткові параметри функції, в залежності від обраного алгоритму.
Ці параметри мають мати чітко визначений тип та встановлене значення за замовчуванням. (`ім'я: тип /* = значення за замовчуванням */`)

> [!IMPORTANT]  
> Важливо пам'ятати, що сигнатура функцій має лишатися незмінною для усіх файлів.
> - Для алгоритмів кластеризайції вона має вигляд:
>   
>   `def Algorithm(points, distance, ... /* Додаткові параметри */) -> list[int]: ...`.
> - А для метрик відстані між об'єктами:
>   
>   `def DistanceMetric(point1/p1/first,  point2/p2/second) -> float: ...`
> 
> Програма не зможе знайти та використати Ваш алгоритм, якщо сигнатура функції буде відрізнятись.
>
> Підтримуваними типами додаткових параметрів для алгоритму станом на зараз є лише типи `int` та `float`.

Після натискання на кнопку `Виконати Кластеризацію`, через деякий час на екрані з'являться результати кластеризації.
![image](https://github.com/user-attachments/assets/69c641ab-220e-4dd7-8e45-caffe4f3a33f)

> [!TIP]
> Кластеризацію можна виконувати безліч разів на одному й тому ж самому наборі, змінюючи при цьому алгоритм, метрику чи окремі параметри.
